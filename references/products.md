## 4. 双臂操作平台（RIG 数据采集主体）

- 双臂 14 自由度（单臂 7：肩 3 + 肘 1 + 腕 3），单臂 5.5 kg，臂展 633 mm
- 准直驱关节（QDD）：高反向驱动性，接触自然顺应，力反馈遥操作
- 全模块化关节：CAN 标准接口，15 分钟更换，可自定义关节组合与臂长
- 开源生态：硬件图纸、控制固件、MuJoCo / Isaac Sim 仿真模型、数据集全部开放，支持 ROS2 / Python API / LeRobot
- 航空级铝材 + 3D 打印复合护罩
- 应用：具身智能研究、力控算法验证、遥操作、人机协作、教育科研、工业原型验证
- 成本：$3,000
