# FlatHill 公司介绍

> 单一事实源。团队更新公司信息时只改这个文件。
> 最近更新：2026-09-05

## 一句话定位

FlatHill 是一家机器人核心硬件平台公司：自研关节电机模组（底层）→ 整机平台（四足狗 / 球形机器人 / 双臂操作平台 / 灵巧手）→ 具身智能数据采集基础设施（RIG），为北美 AI 大厂提供数据采集训练硬件与服务。

## 核心业务

1. **关节电机模组（底层技术）**
   - 微型驱动模组：M01 / M01 Neo / M02，用于灵巧手等精细末端
   - 大关节模组：WZ53 / WZ79 / WZ119（7 / 15 / 60 N·m），用于四足狗、球形机器人、双臂平台
   - 硬件完全自研 + 重庆自有 CNC 车间，BOM 压至外协约 60%

2. **整机平台（数据采集的物理载体）**
   - 双臂操作平台（14-DOF QDD，开源生态，RIG 数据采集主体）
   - 四足机器狗（16-DOF，130 N·m，IP56，智能巡检）
   - 球形机器人 WZ-R700 / ORBIX（IP68 两栖全地形，警用巡逻与巡检）
   - 灵巧手与夹爪系列（2/3/4/5 指，6–21 自由度）

3. **具身智能数据业务（RIG）**
   - 以自研双臂 RIG + 灵巧末端为客户提供真机遥操作数据采集
   - 目标客户：NVIDIA、OpenAI、Amazon、Meta 等北美 AI 大厂的机器人数据训练团队
   - 商业模式：硬件销售 + 数据服务 + RaaS

4. **美国制造计划**
   - 乔治亚州工厂：CNC 机加工 + 半自动化组装，95% 以上美国本土制造
   - 仅从中国进口绕好的铜线线圈、定子、部分电子元器件，整体成本远低于 65% 门槛
   - 背景：FCC 2026-07（DA26-786）将境外生产的先进机器人（人形/四足/轮式）纳入 Covered List，本土组件占比门槛 ≥65%（2029 年升至 70%），美国本土制造可豁免

## 核心优势（客观陈述）

- **全栈自研**：电机、减速器、驱动板、编码器、嵌入式软件全部自研，数据市场饱和后仍保有硬件稳定供应市场
- **成本壁垒**：自有 CNC 产能，BOM ≈ 外协 60%；M01 Neo ¥1,896 vs Maxon 同级 ¥6,000+
- **唯一模块化灵巧手**：Neo 灵巧手是竞品对比中唯一支持关节模块化即插即用的产品
- **地缘合规先机**：FCC 限制下，美国本土制造的硬件供应平台稀缺
